# 线上语义层测评报告

本文档专门记录“线上语义层测试”的测评结果。该测试使用当前系统配置的外部语义模型能力，结合本地规则、变体识别、本地语义兜底和融合决策，评估系统在真实公开样本上的综合审核效果。

## 一、测试目的

线上语义层测试的目标是评估系统在接近真实使用状态下的内容审核能力，重点观察：

- 规则层和语义层结合后的整体准确率；
- 对诈骗、博彩、低俗色情、黑产广告、辱骂引战等明确风险的识别能力；
- 对正常内容的误判情况；
- 对隐晦辱骂、性别歧视、复杂社会讨论等困难样本的表现；
- 外部语义模型相较纯本地模式带来的提升。

## 二、系统参与模块

本次线上语义层测试包含以下模块：

```text
输入文本
  -> L1 词库与正则规则扫描
  -> L2 变体识别
  -> L3 外部语义模型审核
  -> L3 本地语义兜底
  -> L4 融合决策
  -> 处置建议生成
  -> 输出审核结果
```

与本地模式不同，线上语义层测试会调用配置好的外部 LLM，例如 DeepSeek API。外部模型负责补充规则系统难以处理的上下文理解和语义判断。

## 三、数据来源

测试使用 3 个公开中文数据集：

- **COLDataset**：中文攻击性语言数据集，用于测试攻击性评论识别能力。仓库地址：<https://github.com/thu-coai/COLDataset>
- **ChineseHarm-Bench**：中文有害内容数据集，覆盖不违规、低俗色情、博彩、欺诈、谩骂引战、黑产广告等类别。数据集地址：<https://huggingface.co/datasets/zjunlp/ChineseHarm-bench>
- **SWSR**：新浪微博性别歧视评论数据集，用于测试中文性别歧视识别能力。仓库地址：<https://github.com/aggiejiang/SWSR>

本地数据目录：

```text
.tmp-real-datasets/
```

## 四、标签映射规则

由于系统是通用审核系统，而不同数据集标签体系不同，测试时采用如下映射：

- COLDataset 攻击性评论 -> 有害内容，可接受分类：`辱骂` 或 `其他`
- COLDataset 非攻击性评论 -> 安全内容，最高风险不应超过 `提示`
- ChineseHarm-Bench 不违规 -> 安全内容
- ChineseHarm-Bench 低俗色情 -> 有害内容，可接受分类：`低俗` 或 `色情`
- ChineseHarm-Bench 博彩、欺诈、黑产广告 -> 有害内容，可接受分类：`违法广告`、`诈骗` 或 `引流`
- ChineseHarm-Bench 谩骂引战 -> 有害内容，可接受分类：`辱骂` 或 `其他`
- SWSR 性别歧视 -> 有害内容，可接受分类：`辱骂`、`其他`、`低俗` 或 `色情`
- SWSR 非性别歧视 -> 安全内容

二分类统计中：

- `警告`、`违规` 计为有害预测；
- `合规`、`提示` 计为安全或低风险预测。

## 八、结果解读

线上语义层测试体现出以下特点：

- **精确率较高**：总体精确率达到 `0.8729`，说明系统一旦判为风险内容，多数情况下判断较可信。
- **正常内容误判可控**：特异度为 `0.8500`，说明正常内容通过能力较本地规则硬判更稳。
- **显式风险内容识别较好**：低俗色情、博彩、欺诈在 ChineseHarm-Bench 中召回率分别达到 `0.8500`、`0.8500`、`0.9000`。
- **复杂语义仍是短板**：SWSR 性别歧视样本、隐晦辱骂、编码表达、复杂社会讨论仍然表现较弱。
- **黑产广告在当时测试中偏弱**：黑产广告通过率为 `6/20`，主要问题是短句黑话和任务广告表达过短，例如“抄小说吗”“dy评论”等。

## 九、和本地模式对比

本地模式关闭外部语义模型，仅使用词库、变体、本地语义兜底和融合逻辑。对比结果如下：

| 测试模式 | 样本数 | 准确率 | 精确率 | 召回率 | F1 | 特异度 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 线上语义层测试 | 280 | 0.6714 | 0.8729 | 0.5722 | 0.6913 | 0.8500 |
| 本地模式测试 | 420 | 0.4952 | 0.8295 | 0.2704 | 0.4078 | 0.9000 |

结论：

- 线上语义层显著提升召回率和 F1；
- 本地模式更稳定、可复现、成本低，但语义理解能力不足；
- 商用或正式展示时，线上语义层更接近真实使用效果；
- 离线调试、规则回归、冒烟测试适合使用本地模式。

## 十、主要失败类型

失败样本主要集中在以下几类：

- **隐晦辱骂**：例如谐音、暗语、反讽式攻击；
- **性别歧视和社会议题讨论**：SWSR 中大量样本依赖语境判断，容易漏判或误判；
- **黑产广告短句**：短到只有“抄小说吗”“dy评论”等信号时，当时系统召回不足；
- **分类漂移**：有些内容能识别为风险，但分类落到 `涉政`、`色情`、`违法广告` 等邻近类别；
- **安全讨论误判**：讨论法律、性侵、族群、性别议题时，容易因敏感词被抬高风险。

## 十一、结论

本次线上语义层测试说明：系统在明确风险场景下已经具有较好的实用价值，尤其是低俗色情、博彩、欺诈等类别；整体精确率较高，适合作为审核辅助系统或课程设计中的核心实验结果。

但系统还不是完整商用级审核模型。它在隐晦辱骂、性别歧视、软诈骗、黑话广告和复杂上下文判断上仍需要继续增强。后续优化方向应包括：

- 引入更强的语义分类器或更严格的 LLM 审核 rubric；
- 建立专门的辱骂/歧视/黑产广告样本集；
- 对分类阈值进行分类型校准；
- 增加人工复核队列，用于承接不确定内容。
