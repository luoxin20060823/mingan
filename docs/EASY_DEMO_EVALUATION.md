# 演示友好评测报告

本文档记录一组“简单、典型、适合演示”的内容审核评测结果。该评测集用于产品演示、冒烟测试和快速展示系统能力，不应替代 `REAL_WORLD_EVALUATION.md` 中的综合真实样本评测。

## 评测目的

综合真实样本中包含大量边界复杂、隐晦表达、讽刺语境和标签口径差异，适合评估系统真实上限和短板，但演示时不够直观。本评测集专门选择更清晰的样本类型，用于展示系统在典型场景下的稳定表现：

- 正常内容应放行；
- 明确黑产广告应识别为风险；
- 指标应便于向非技术人员说明。

## 数据来源

本次使用公开数据集 **ChineseHarm-Bench** 的两个子类：

- `不违规.json`：正常、非违规内容；
- `黑产广告.json`：黑产任务、异常兼职、代发代评等广告内容。

数据集地址：<https://huggingface.co/datasets/zjunlp/ChineseHarm-bench>

本地数据路径：

```text
.tmp-real-datasets/ChineseHarm-bench
```

## 样本选择

本次每类抽取 10 条，共 20 条：

| 类别 | 样本数 | 预期 |
| --- | ---: | --- |
| 不违规 | 10 | 风险等级不高于 `提示` |
| 黑产广告 | 10 | 风险等级至少为 `警告`，分类为 `违法广告`、`诈骗` 或 `引流` |

该选择是有意设计的 easy benchmark：样本更典型、边界更少，适合演示系统优势。

## 运行命令

```powershell
Remove-Item Env:DEEPSEEK_API_KEY -ErrorAction SilentlyContinue
python scripts/evaluate_easy_demo_samples.py --per-category 10 --output-dir .tmp-real-eval/easy-demo-20-local-clean
```

## 失败样本

唯一失败样本：

```text
哒字砖米感兴趣吗？
```

预期：黑产广告，至少 `警告`。  
实际：`合规`。

该样本属于高度隐晦黑话，需要额外补充黑产语义规则或依赖更强语义模型识别。

## 结论

这组简单评测能够较好展示当前系统的实用能力：

- 正常内容放行稳定，10 条全部通过；
- 明确黑产广告识别较好，10 条通过 9 条；
- 总体准确率达到 `95.00%`，F1 达到 `0.9474`；
- 没有出现误拦正常内容的情况。

但必须注意：该评测集是演示友好子集，不能代表系统在所有真实场景中的综合能力。复杂真实场景仍应参考 `REAL_WORLD_EVALUATION.md`。
